Object Initialization

Objects are created with the form (new type[ arg ..]). The length element of the type has the following effect:

length = 0
The length of the new object is the length of the argument list. If no arguments are given a zero length object of type is created.
length > 0
The length of the new object is of the given length.
length < 0
The argument list is asserted to be a multiple of -length, an error is returned if not. The length of the new object is set to the length of the argument list.

The difference between a length field of 0 and of -1 is, that the latter requires the object to have at least one element.

If the new element of type is nil the elements are set to the given arguments, the first element is set to the first argument and so forth. If more then length arguments are given the extra arguments are silently ignored, if less then length arguments are given, the remaining elements are set to nil.

If the new element of the type is not nil, it must be a primitive or lambda, otherwise an error is returned. An object is created with a length according to the above rules, then (new object[ arg ..]) is evaluated.

Better alternative:

(new type[ arg ..]) is evaluated. It must return a list. Then new is evaluated with the list as arguments as if the new element was set to nil.

Objects are created with the new primitive. If the new field of the type is nil, (new type[ arg ..]) creates an object of type depending on the length element follows:

length = 0
The length of the new object is the length of the argument list, the elements are initialized it with the given arguments. If no arguments are given a zero sized object of type is created.
length > 0
The length of the new object is of the given length, the elements are initialized with the list of arguments. If more then length arguments are given the extra arguments are silently ignored. If less then length arguments are given, the remaining elements are set to nil.
length < 0
The argument list is asserted to be a multiple of -length, an error is returned if not. The length of the new object is set to the length of the argument list and the elements are initialized with the given arguments.

The difference between a length field of 0 and of -1 is, that the latter requires the object to have at least one element.

If the new field of the type is not nil, it must be a primitive or lambda. (new type[ arg ..]) creates an object of type depending on the length element follows:

length = 0
(new[ arg ..]) is evaluated. If it evaluates to a list ([arg ..]) then (new type[ arg ..) is evaluated as described above, otherwise an error is returned.
length > 0
An object of the given length with all elements set to nil is created, then (new object[ arg ..]) is evaluated.
length < 0
The argument list is asserted to be a multiple of -length, an error is returned if not. A new object with the length of the argument list and all elements set to nil is created. Then (new object[ arg ..]) is evaluated.

 Zero length Objects

Different objects with length = 0 and the same type are compared as same.
